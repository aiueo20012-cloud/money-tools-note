📱 格安SIMを選ぶ前の6つのチェックポイント

「乗り換えて安くしたいけれど、失敗したらどうしよう」と不安な方へ。契約手続きを行う前に、以下の6項目をひとつずつ確認しておくと安心です。

1. 今のデータ使用量を確認する

最も重要なのが「自分が毎月何GB使っているか」の把握です。現在契約しているキャリアのマイページ（My docomo、My au、My SoftBankなど）にログインし、過去3か月分のデータ通信量を確認しましょう。

「無制限プランに入っているけれど実際は月5GBしか使っていなかった」というケースも多く、実際の消費量に合ったプランを選ぶだけで大幅に安くなります。

2. 通話時間と通話方法を確認する

家族や友人との連絡はLINE通話などの無料アプリで済んでいるのか、それとも仕事や予約などで通常の電話番号発信をよく使うのかを確認します。

通常通話をほとんどしない場合は「通話オプションなし」にすれば月額料金を抑えられます。長電話が多い方は「5分かけ放題」や「完全かけ放題」のオプションが用意されている事業者を選びましょう。

3. 自宅・職場・学校で使う場所の電波を考える

スマートフォンを使う主な生活圏（自宅、職場、学校、通勤路など）の電波状況を確認します。格安SIMは大手キャリア（ドコモ・au・ソフトバンク・楽天モバイル）の電波を借りて提供されているため、生活圏で強いキャリアの回線を選ぶのが基本です。

また、自宅にWi-Fiがある場合は、スマホのモバイルデータ通信量を少なく抑えられるため、より小容量プランを選択できます。

4. 乗り換え前に解約条件と端末残債を確認する

現在のキャリアで端末を分割購入している場合、乗り換え後も端末の分割払いは継続します（一括清算も可能な場合が多いです）。

また、契約解除料（違約金）は多くのプランで撤廃されていますが、古い料金プランをご利用の場合は更新月や違約金の有無を念のため確認しておきましょう。

5. 家族割・光回線セット割の影響を確認する

家族で同じキャリアを使って割引を受けている場合や、自宅の固定インターネット回線（光回線）とのセット割引が適用されている場合は注意が必要です。

自分1人が他社へ乗り換えたことで、家族の月額料金が高くなったり、光回線の割引が減額される場合があります。世帯全体のトータル出費で得になるかを計算しましょう。

6. 料金、キャンペーン、通信品質は各公式サイトで確認する

格安SIMの料金プランやキャンペーン内容は頻繁に更新されます。また、混雑時間帯（お昼休みや夕方）の通信速度やサポート体制（店舗の有無、チャット対応など）も事業者ごとに異なります。

必ず各通信会社の公式サイトにアクセスし、最新の重要事項説明や注意事項をご自身の目で確認してください。

乗り換え検討時のご注意 乗り換え（MNP）を行う際は、事前に現在お使いのスマホが乗り換え先の会社で動作確認されているか（動作確認済み端末一覧）も公式サイトで必ずチェックしてください。

⚖️ 格安SIM比較の考え方

当サイトでは、根拠のない「人気No.1」「最安」「絶対おすすめ」「必ず得」といった断定的なランキング付けは行いません。
利用者の使い方（ギガ数・通話頻度・サポート要望）によって最適な選択肢はまったく異なるためです。ここでは客観的な比較軸と整理方法を解説します。

料金以外の「6つの比較基準」

格安SIMを比較する際は、表面上の月額基本料だけでなく以下の要素を総合的に確認することが後悔しないコツです。

  • データ容量の刻み: 1GB、3GB、5GB、10GB、20GBなど、自分の実利用量にぴったり合うプランがあるか
  • 通話オプションの柔軟性: 5分・10分の短時間かけ放題があるか、専用通話アプリが不要か
  • 通信速度と回線品質: お昼の12時台や夕方の通勤時間帯に極端な速度低下がないか（大手サブブランドやオンライン専用プランは比較的安定）
  • サポート体制: 店舗で対面サポートを受けたいか、Webやチャットサポートだけで十分か
  • 初期費用と手数料: 契約事務手数料やSIM発行手数料が無料か有料か
  • 縛りと解約条件: 最低利用期間や違約金がないか、MNP転出がスムーズか

📖 初心者のための挫折しない「家計簿の始め方」

「家計簿を始めてみたけれど、レシート入力が面倒ですぐやめてしまった」という経験はありませんか？
家計管理で大切なのは、1円単位で完璧に記録することではなく、家計の大枠を把握することです。

家計を構成する「5つの基本要素」

家計のお金の流れは、大きく分けて次の5つに分類できます。

項目 具体例 管理のポイント
1. 収入 給与手取り額、賞与、副収入など 額面ではなく「実際に口座へ入金される手取り額」で考える。
2. 固定費 家賃、通信費、サブスク、保険、水道光熱費 毎月ほぼ決まって出ていくお金。一度見直せばずっと効果が続く。
3. 変動費 食費、日用品費、交際費、娯楽費、被服費 日々の行動で変わるお金。無理に削りすぎるとストレスの原因に。
4. 予算 各費目に使える毎月の上限目安額 細かく分けすぎず、「変動費全体で月〇万円」のようにざっくり決める。
5. 貯金 生活防衛資金、目的別積立 「余ったら貯金」ではなく「給料日に先に別口座へ移す（先取り）」が鉄則。

家計簿を完璧に続けなくてよい理由

多くの人が家計簿を挫折する原因は、「毎日のレシートを1枚ずつ品目別に打ち込もうとする」からです。

しかし、コーヒー代の150円をメモすることに何十分も時間をかける必要はありません。家計改善で最も効果的なのは、金額が大きく毎月自動で口座から引き落とされる「固定費」を把握することです。

まず「月の固定費」を知ることから始めよう

家計改善の第一歩として、まずは以下の3つだけをやってみましょう。

  1. 通帳やクレジットカードの明細を開き、毎月定期的に引き落とされている項目を書き出す
  2. 当サイトの固定費チェック診断に入力して、月額と年額の固定費合計を計算する
  3. 「使っていないのに引かれているサブスク」や「高すぎるスマホ代」がないかを確認する

💡 固定費見直しの基本とチェックポイント

支出の見直しには「固定費」と「変動費」の2種類があります。
なぜ節約は固定費から始めるべきなのか、主要な5項目で見直す前に確認すべきポイントをまとめました。

固定費と変動費の違い

食費や電気のこまめな消灯といった「変動費の節約」は、毎日の生活の中で常に我慢や意識を強いられ、努力をやめると出費が戻ってしまいます。

一方で、スマホ代やサブスクなどの「固定費の節約」は、見直し手続きを行うのは最初の1回だけです。一度手続きを完了すれば、翌月以降は生活満足度を落とすことなく、毎月自動的に数千円〜数万円の支出が減り続けます。

主要項目別の「見直す前に確認すべきこと」

1. スマホ代（通信費）

毎月のデータ使用量（GB）、通話オプションの要否、端末の分割残金を確認します。大手キャリアから格安SIMやサブブランドへ変更するだけで月3,000円〜5,000円程度の節約になるケースが多く、最も効果が出やすい分野です。

2. サブスクリプション

直近1か月以内にそのサービスを利用したか、年間契約の自動更新時期がいつかを確認します。「無料期間だけ使うつもりで忘れていたもの」は即解約しましょう。

3. 保険料

日本には国民健康保険や健康保険による「高額療養費制度」があり、一般的な所得であれば1か月の医療費自己負担には上限が設けられています。公的医療保険の保障内容を理解した上で、民間の医療保険や生命保険で過剰・重複な保障に入っていないか確認しましょう。

4. 電気・ガス

電力・ガス会社を変更しても、送電網やガス管は従来と同じものが使われるため、供給の安全性や品質が変わることはありません。ただし、解約時の違約金や燃料費調整額の計算方法については各社公式サイトで確認が必要です。

5. インターネット回線

光回線の工事費残債やプロバイダの解約違約金、スマホとのセット割の適用条件を確認します。キャッシュバックキャンペーンを利用する場合は、受け取り時期や手続き期限をメモしておきましょう。

特定サービスへの誘導はいたしません 利用者の居住地域や家族構成、ライフスタイルによって最適なサービスは異なります。特定事業者への乗り換えを断定的に勧めることはせず、公式サイトで条件を確認して納得の上で判断することをおすすめします。

📦 GitHub Pagesでの公開手順（静的サイト運用ガイド）

本サイトは index.html、style.css、script.js の3ファイルだけで動作する完全な静的サイトです。GitHubのリポジトリにそのまま配置して公開できます。 

# 構成ファイル一覧
├── index.html   (全14ページを統合したHTML5)
├── style.css    (濃紺・白・薄青・緑のレスポンシブCSS)
└── script.js    (ルーター・バリデーション・計算ロジック)

# GitHub Pages公開手順
1. GitHubで新しい公開リポジトリを作成
2. index.html, style.css, script.js をリポジトリのルートへプッシュ
3. リポジトリの [Settings] → [Pages] を開く
4. Sourceで「Deploy from a branch」、Branchで「main / (root)」を選択してSave
5. 数分後に公開URL（https://ユーザー名.github.io/リポジトリ名/）で閲覧可能になります
